# A Plus Master Jeon Tae Kwon Do

Website for A Plus Master Jeon Tae Kwon Do, 23 West Main St, Chester, NJ 07930.

A single static page (`index.html`) with no build step. It is hosted with GitHub Pages.

## Editing

| What | Where in `index.html` |
| --- | --- |
| Class schedule | the `sched` object in the script at the bottom |
| Pro Shop items and prices | the `products` array in the script at the bottom |
| Hero photo | `images/class-photo.jpg` |
| Hours, phone, address | the top bar, Contact section and footer |
